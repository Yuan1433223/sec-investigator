> 用途：A2 暗色控制台已完成。代码冻结后的**成品截图、GIF、录屏、仓库配置**属于纯执行环节，由你本人本地操作即可，不必再走 AI（省时间、省 token，且本地一遍过的效果更好）。本手册给你零思考成本的动线和清单。

## 一、环境准备（只做一次）

```bash
# 项目根目录 F:\kks-pure
uv sync                      # Python ≥ 3.12，安装后端依赖
# .env 已配置智谱 GLM（OPENAI_API_KEY / OPENAI_BASE_URL），fake 模式不需要任何内网
cd web
npm install                  # 前端依赖（Tailwind v4 + shadcn 已在 package.json）
npm run build                # 产物 dist/，由 FastAPI 在 :18230 直接托管
cd ..
```

> 之后每次演示，前端没改就不用重新 build；改了前端必须重新 `npm run build` 并**硬刷新浏览器**（Ctrl+F5），否则会看到旧 bundle（A1 踩过这个坑）。

## 二、启动与演示动线

```bash
uv run sec-investigator      # 启动 FastAPI，默认 http://localhost:18230
```

浏览器打开 `http://localhost:18230`（建议 Chrome/Edge，窗口宽度 ≥ 1440px）。

**黄金演示路径（incident2 = 5xx 源站应用故障，必出 critical + 审批）：**

1. 在首页选择 **incident2**（5xx 源站故障；若界面是输入框则填目标 `api2.xs2027.cn`），开始调查
2. 观察顶部**六步状态灯流水线**推进（灰→蓝脉冲→绿；审批门变琥珀=待审批）
3. 左侧调查流看**四列泳道**：日志侦探 / 机器检查 / 安全防护 / 审批·报告；machine、security 泳道内按资产分子轨（如 118.178.13.52 / .53 并排）
4. 工具调用实时出现为卡片；点卡片标题可**展开** mono 字体的入参/输出 JSON（折叠树范式）
5. 调查到高危时弹出**人工审批弹窗**（暗色 + 毛玻璃遮罩）→ 点「**批准并继续**」
6. 右侧/底部出现**结构化报告**：告警状态横幅（critical 红）、根因（源站 5xx 70%）、证据数据网格、编号处置建议

命令行等价演示（无 UI 时备用）：

```bash
uv run python examples/run_demo.py api2.xs2027.cn   # 5xx（critical，主推）
uv run python examples/run_demo.py game.ali213.net  # 4xx 爬虫扫描
uv run python examples/run_demo.py kk331dsdi32onew.liu6t.cn  # 高并发过载
```

## 六、轻量回归（你自己一条命令就能验，不必等 AI）

```bash
uv run pytest -q          # 期望：551 passed，离线秒级
cd web && npm run build   # 期望：tsc strict + vite build 通过
```

- 测试红了 / build 失败：把完整输出贴给 AI 分析（分析是决策环节，AI 做）。
- 演示中偶发 LLM 分析文本与确定性数字口径不一致（如文本写 34.4%、确定性 70.0%）：**以确定性数字为准**，这是已知限制（GLM 行为问题），定级和报告都走确定性值，不影响闭环。
- GLM 偶发返回 None 已在 A2 兜底（三 worker + reporter），不会再以 `'NoneType' has no attribute 'model_dump'` 终止；若仍见到报错，截图 + 后端日志发 AI。
- 端口 18230 被占：`netstat -ano | findstr 18230` 查 PID，`taskkill /PID <pid> /F` 清掉旧进程。

## 七、B 线中需要你本人/本企业环境的部分

- **real 模式联调**：`.env` 设 `DATA_SOURCE=real` 后，ES/Prometheus/WAF/GF 的地址与凭据、企业 VPN 只有你有；AI 负责代码和配置模板，你在内网跑、把报错日志喂回来。
- 部署：服务器/域名/DNS/SSL 的采购与配置；模型资源包充值。
- RBAC 角色矩阵：AI 出草案，你按真实团队分工拍板。
